# Amazon Clone

A frontend Amazon homepage clone created using HTML and CSS as a practice project while learning web development.

# Overview

This project replicates the basic layout and visual appearance of Amazon's homepage. It focuses on practicing HTML structure, CSS styling, Flexbox, and layout design.

# Features

- Amazon-inspired navigation bar.
- Search bar layout.
- Hero section with a promotional message.
- Product category sections.
- Footer with multiple navigation sections.
- Font Awesome icons.

# Technologies Used

- HTML5
- CSS3
- Font Awesome

# How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
